# Сайт Banana Club

Волгоград, улица Хорошева, 99. Детская игровая и организация праздников.
Одностраничный сайт: пакеты, персонажи, конструктор праздника, выбор свободной даты и заявка.

## Что здесь лежит

| Файл | Зачем |
|---|---|
| `index.html` | вся страница |
| `css/style.css` | оформление |
| `js/config.js` | цены, пакеты, персонажи, часы работы — правится здесь, остальной код трогать не нужно |
| `js/app.js` | корзина праздника, календарь свободных дат, форма заявки |
| `js/bubbles.js` | мыльные пузыри в первом экране |
| `js/foilrain.js` | фольга в разделе с пакетами |
| `js/effects.js` | эффекты при выборе шоу: пузырь лопается, фольга разлетается |
| `policy.html` | политика обработки персональных данных |
| `img/` | фотографии |

## Как обновляется

Рабочая версия сайта живёт на компьютере в `banana\site\www`. Эта папка — копия,
собранная скриптом `banana\site\sobrat-dlya-publikacii.ps1`, и только она уезжает в интернет.
Прошлая версия вёрстки (`index.old.html`, `style.old.css`) остаётся на диске для отката
и в копию не попадает.

## Заявки

Заявка с сайта уходит в программу Google Apps Script в аккаунте клуба, оттуда бронь
попадает в Google Календарь. Свободное время на сайте тоже читается из этого календаря.
Адрес программы указан в `js/config.js`. Если его стереть, сайт перейдёт в демо-режим:
форма работает, но заявки никуда не уходят.
